无尽冬日 自动点击治疗脚本

一款专为《无尽冬日》游戏设计的自动化工具，支持自动点击治疗、自动狩猎等功能，提升游戏体验

立即安装 了解更多

核心功能特性

强大的自动化功能，让游戏操作更加便捷高效

自动点击治疗

配置治疗按钮坐标后，脚本将自动执行点击操作，无需手动操作即可完成治疗流程

自动狩猎功能

支持配置多步骤坐标点，实现完整的自动化狩猎流程，提高资源获取效率

坐标点拾取

提供两种坐标获取方式：右键点击拾取和实时坐标显示，支持3秒自动复制功能

灵活配置

所有功能均支持自定义配置，可根据个人需求调整点击位置和执行顺序

简单易用

基于 Python 开发，安装依赖即可运行，无需复杂的配置过程

安全可靠

本地运行，无需联网，确保游戏账号和数据安全

使用指南

快速上手，只需几个简单步骤

1

创建环境

conda create -n wujindongri python=3.10.13 -y
2

激活环境

conda activate wujindongri
3

安装依赖

pip install -r requirements.txt
4

运行脚本

python main.py

坐标点获取工具

A

右键点击拾取

主动右键点击屏幕拾取坐标点，默认右键点击后自动退出监听

python getpoints_by_click.py
B

实时坐标显示

打印当前鼠标所在坐标，超过3秒自动复制当前鼠标所在坐标

python getpoints.py

自动狩猎功能

配置坐标组后自动执行狩猎流程

python auto_hunting.py

* 在 auto_hunting.py 中配置需要点击的坐标组（自动狩猎一般配置4个步骤点即可）

常见问题

快速了解项目相关信息

支持哪些Python版本？
建议使用 Python 3.10.13 版本，使用 conda 创建环境可以确保版本一致性。
如何获取屏幕坐标点？
提供两种方式：使用 getpoints_by_click.py 进行右键点击拾取，或使用 getpoints.py 实时显示鼠标坐标并支持3秒自动复制。
自动狩猎需要配置多少个坐标点？
一般配置4个步骤点即可完成完整的狩猎流程。具体坐标点根据游戏界面和个人需求进行配置。
脚本运行时需要注意什么？
运行前确保已正确配置所有需要的坐标点，保持游戏窗口在前台显示，避免其他操作干扰脚本执行。
